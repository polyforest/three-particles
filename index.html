three-particles

A particle engine for THREE.js. An effect is a JSON document describing emitters, textures, zones, and timelines. Load one, add it to your scene as a Group, and call update() once per frame.

npm install three-particles

Get started

  1. Install the library. It is ESM-only and expects three >=0.186.1 <0.187.0 as a peer dependency: 
    npm install three-particles
  2. Load an effect and add it to your scene: 
    import { ParticleEffect, ParticleEffectLoader } from 'three-particles'

const model = await new ParticleEffectLoader().loadAsync('./fire.json')
const effect = new ParticleEffect(model)
scene.add(effect)

// Once per frame, with the frame delta in seconds:
effect.update(delta)
  3. Or skip the setup and .

The full effect JSON format (emitters, timelines, zones, eases, materials) is documented in the usage guide.

Author effects visually

The particle editor edits effects in the browser and exports the same JSON the runtime loads, so what you design there drops straight into your scene. The tornado in the demo was made with it.
